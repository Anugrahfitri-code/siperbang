# Frontend Tidak Aktif

Folder ini menyimpan kode frontend yang tidak masuk graph import Vite aktif.

- `data/data.ts` berisi data contoh lama.
- `hooks/useConfirm.tsx` berisi hook konfirmasi yang belum dipakai komponen aktif.
- `styles/index.css` tidak diimpor oleh entry point Vite aktif. CSS aktif berada pada `resources/css/app.css`.

File disimpan untuk referensi. Pindahkan kembali ke `resources/js/` hanya setelah dipakai dan diuji.
