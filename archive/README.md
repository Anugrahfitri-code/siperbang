# Archive

Folder ini menyimpan materi yang tidak digunakan oleh runtime aplikasi.

- `prototypes/desain-temp/`: prototipe frontend Vite terpisah.
- `frontend/unused/`: source frontend tanpa referensi pada graph import aktif.
- `assets/unused/`: aset tanpa referensi runtime.
- `legacy/laravel/`: controller, request, view, layout, dan test lama yang sudah digantikan alur aktif.

Source aktif berada pada `app/`, `resources/`, `routes/`, `database/`, dan `ocr-service/app/`.

File arsip tidak diperbarui mengikuti namespace atau path source terbaru. Gunakan hanya sebagai referensi historis.
