# Prototipe Desain Lama

Folder ini menyimpan prototipe frontend yang dibuat sebagai aplikasi Vite terpisah. Prototipe ini tidak masuk proses build SIPERBANG.

Kode frontend aktif berada pada `resources/js/`.

Gunakan prototipe ini hanya sebagai referensi visual. Jangan menyalin perubahan langsung ke aplikasi aktif tanpa meninjau perbedaan API, tipe data, autentikasi, dan komponen.

Untuk menjalankannya secara terpisah:

```bash
npm install
npm run dev
```

Konfigurasi contoh tersedia pada `.env.example`. Jangan simpan API key asli di dalam repository.
