# Legacy Tools

Isi folder ini berasal dari perbaikan satu kali dan eksperimen lama. Aplikasi tidak memanggil file-file ini.

Jangan menjalankan script perbaikan data langsung pada database produksi. Tinjau filter, ID, nama pengguna, dan dampak perubahan data terlebih dahulu. Buat backup database sebelum eksekusi.

`tinker-snippets/` berisi potongan kode untuk `php artisan tinker`. File tersebut bukan perintah CLI mandiri.
